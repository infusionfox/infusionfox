# Code of conduct

InfusionFox is a clinical reference tool. Contributors are expected to act
like clinical colleagues.

- Disagree with the content, not the person.
- Issues and PRs are about calculators, sources, and code. Stay on topic.
- Cite sources for clinical claims. Edition and page numbers please.
- Never post patient-identifying information.
- Assume good faith. Most disagreements are about edge cases or unclear
  sources, not bad intent.

Personal attacks, harassment, and spam will be removed. Persistent or severe
violations result in a ban from the repository.

Report concerns to support@infusionfox.com.
