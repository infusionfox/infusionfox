Lives in base.html so the drawer works on every page. Wires up hamburger → open, close button → close, backdrop click → close, Escape → close. Manages aria-expanded and aria-hidden so screen readers track the state. #} {# Global Enter-in-form handler. Calculator forms throughout the site use HTMX with hx-trigger="input changed delay:250ms, change, load". That works for typing (input event) and for tabbing/clicking out (change event), but Enter inside a single-input form historically caused a confusing behavior: some forms recomputed, some didn't, and a few would attempt a full page navigation depending on which browser and which form structure was rendered. This shim normalizes Enter across every form on the site: (1) prevent the browser's default submit (no page reload), (2) blur the active field so its change event fires (which HTMX is already listening for), and (3) explicitly trigger HTMX's change on the form as a belt-and-suspenders measure in case (2) didn't fire. The result: Enter behaves the same as Tab — instant compute, no page reload, regardless of which calculator the user is in. Forms that don't use HTMX (none currently, but a defensive check) fall through to the browser's normal submit. #} {# ===== Hard-block disclaimer modal ===================================== Shown on first visit and after every DISCLAIMER_VERSION bump.
